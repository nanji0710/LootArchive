## 0. 从 SleepDown 学到的四条结构原则

1. **一级导航只放页面，不放动作**：SleepDown 底栏是「今日 / 课程表 / 设置」三个导航胶囊 +
   最右侧一个**独立圆形加号**。加号不属于 Tab，不参与选中态 —— 点它永远只表示「新增」。
2. **设置页是功能地图**：大标题 + 搜索框 + 应用卡 + 若干分组卡片；每组由彩色图标导航行组成，
   行内只有标题，说明留给二级页；每个功能只有一个入口。
3. **视效设置要有预览**：SleepDown 的视效页先给一块实时预览，再给分档/滑杆；只写文字说明，
   用户无法判断「改了会怎样」。
4. **检查更新是状态页而不是弹窗**：版本卡 + 内联状态（检查中 / 已是最新 / 有新版本 / 失败）+
   更新日志 + 下载进度，全部在当前页面完成。

## 5. 外观与视效 / 图标风格（点击就地展开，不跳页）

**文件**：`ui/theme/Appearance.kt`（新增）、`ui/theme/Theme.kt`、`ui/settings/GeneralSettingsScreen.kt`、
`ui/component/PreferenceRows.kt`（`DropdownPreferenceRow`）、`ui/liquidglass/LiquidGlassButton.kt`、
`LiquidIconButton.kt`、`LiquidGlassBottomBar.kt`、`ui/component/PageTopBar.kt`、`ui/component/AmbientOrbs.kt`

- **交互严格对齐 SleepDown**：视效模式 / 图标风格用 `DropdownPreferenceRow` —— 点行后
  在行下方浮出一块圆角菜单（`Popup`，不占布局、不推动下方内容），选中项右侧显示 ✓，
  点选项立即生效并收起；行尾箭头随展开旋转 180°。**不再跳转独立外观页**（该页已删除）。
- **视效模式**三档：
  - 沉浸：全屏暖色光斑（`AmbientOrbsBackground`）+ 全量玻璃模糊 + 共享元素飞行；
  - 均衡：静态渐变 + 玻璃，无环境动效（默认）；
  - 省电：纯色背景 + 实色面板（按钮/图标按钮/底栏都改为不透明）+ 关闭共享元素飞行。
- **图标风格**三档：圆润（实心）/ 线性（线框）/ 双色（实心 45% 底衬 + 线框）。
  生效范围：底栏、顶栏返回键、设置行、首页助手入口、检查更新页、AI 助理页。
- 通用设置首段同样提供亮/暗预览卡 + 跟随系统开关 + 两个下拉行，与 SleepDown 的
  「通用设置 → 外观」结构一致。

## 6. 新增物品打开动画

**文件**：`ui/MainScreen.kt`、`ui/nav/NavShared.kt`、`ui/additem/AddItemScreen.kt`

- 加号按下：按钮位置扩散两圈光环（`drawBehind`，不建图层）。
- 页面：共享元素从按钮矩形撑满全屏；表单内容用 `navRiseIn` 从下方 18dp 上浮落位；
  顶栏反向轻移 -8dp。返回时整套动作反向播放。
- `navRiseIn` 用布局位移实现（不是 graphicsLayer），避免液态玻璃与图层链互相引用造成渲染线程崩溃。

```powershell
# 1) 构建 debug
cd D:\GitHub\LootArchive
.\gradlew.bat :app:assembleDebug --offline

# 2) 覆盖安装（设备 BKQ-AN10，Android 17）
$adb = 'C:\Users\RED CHAMBER\Android\Sdk\platform-tools\adb.exe'
& $adb devices -l
& $adb install -r app\build\outputs\apk\debug\LootArchive-debug-v7.5.5.apk

# 3) 启动
& $adb shell am force-stop com.nanji.lootarchive
& $adb shell am start -n com.nanji.lootarchive/.MainActivity
```

1. 底栏：首页 / 统计 / 助手 / 设置 四胶囊 + 最右独立圆形加号；点加号观察扩散光环与页面撑开。
