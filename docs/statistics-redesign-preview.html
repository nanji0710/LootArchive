统计页改版方案 · v7.2 预览

数据全部由一份 mock 物品表实时计算，与真机口径一致；改时间筛选所有图表联动

信息架构

  • 合并去重：原「分类资产分布」与「分类排名」是同一份数据的两次陈述 → 合成一张资产结构卡（环形图 + 带排名的图例）。
  • 顺序重排：总览 → 结构 → 趋势 → 洞察，四段式；金额类在前，行为类在后。
  • Hero 扩容：右上的「物品总数」小面板换成一行纯文字事实条 —— 在持件数 / 分类数 / 平均单价（新增），不做卡片。
  • 筛选器：留在 Hero 内，但宽度拉满、与卡片同宽；滚动时淡出（真机可实现吸顶）。
  • 零指标卡：整页不再有「小方块数字」。需要读的量全部交给图本身（柱高、条长、虚线、端点徽标、卡片角标）。

新增图表

  • 客单价分布新
    5 档价格区间直方图，件数最集中的档位高亮。回答「我这堆东西是精品还是杂货」。
  • 单品价值 TOP 5新
    带奖牌的排行榜，一眼看到「钱压在哪几件上」。
  • 存放位置分布新
    storageLocation 的金额/件数分布。

替换与修复

  • 删掉雷达图删除
    原「分类多维对比」5 条轴全是「金额」一项归一化，等于把排行画成圆——没有第二维度。排名已经在资产结构卡里用条形 + 百分比讲清楚了，不需要再来一张。
  • 趋势图补齐空月修复
    现实现只 groupBy 有购入的月份，没买的月份整段消失，x 轴不等距（StatisticsScreen.kt:324-330）。补 0 后时间轴才可言。
  • 柱状图高亮口径修复
    现在是「最高月」高亮（StatisticsScreen.kt:355），改用当月高亮 + 月均虚线，回答的是「我最近买得凶不凶」。
  • Y 轴刻度修复
    趋势图加 4 档金额刻度，现在只能靠端点徽标猜量级。
  • 图表无障碍保留
    沿用现有 semantics { contentDescription } 摘要，新图表一并补上。
  • 删掉物品状态删除
    生命周期占比（在用/闲置/待修/已出/丢失）在首页列表里一眼就能看出来，统计页不值得为它占一整张卡。
  • 删掉保修到期删除
    warrantyExpiryDate 虽有数据，但本质是「提醒」而不是「统计」，更适合放首页或通知，不该混在资产分析里。

刻意没做的

  • 不新增标签云 —— 标签录入在 v7.0 已按方案 A 移除，数据稀疏。
  • 不做入库热力图 —— 与「月度购入」重复，且手机宽度下 43 个月格子太碎。
  • 没有改任何数据口径，全部沿用「仅在用/闲置/待修的购入价计入资产」。
